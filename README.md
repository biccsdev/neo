# NEO

NEO is a voice-first computer-operations plugin for [Hermes Agent](https://github.com/NousResearch/hermes-agent).

The initial release targets macOS and orchestrates coding specialists, Blender, browser workflows, and reusable Hermes capabilities. The architecture is portable; Windows and Linux support is intended but not yet validated.

## Status

Implementation is in progress. The plugin is not yet ready for installation or production use.

## Repository layout

The repository root is the installable Hermes plugin package. It contains the Python agent plugin, FastAPI backend, Desktop page, bundled skills, resources, and tests.
